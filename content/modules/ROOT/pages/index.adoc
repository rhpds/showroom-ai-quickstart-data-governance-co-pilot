= AI-Powered Database Analytics with Built-in Governance

Welcome to the AI-Powered Database Analytics with Built-in Governance workshop!

== What you'll learn

In this workshop, you will:

* Understand the 40-year evolution of text-to-SQL and why LLM-based agentic AI succeeds where earlier approaches failed
* Master the fundamentals of agentic loops, Model Context Protocol (MCP), and governance-aware database analytics
* Gain hands-on experience running natural language queries, exploring schemas, and observing automatic governance validation
* Explore advanced analytics with multi-step queries and understand orchestration mechanics at a deep level
* Learn how MCP tools are discovered, formatted for LLMs, and secured through deep parse tree validation
* Evaluate architectural choices between custom and framework-based orchestration approaches
* Discover how this approach leverages existing PostgreSQL investments while achieving data sovereignty on OpenShift AI

== Who this is for

This workshop is designed for developers, architects, SREs, and technical/business decision makers who want to understand how to build AI-powered analytics with built-in governance controls.

**Experience level**: Beginner to Intermediate

== Prerequisites

Before starting this workshop, you should have:

* Basic understanding of databases and SQL
* Familiarity with AI/ML concepts (helpful but not required)
* Basic knowledge of OpenShift (helpful but not required)
